# DMCA-Compliance und Takedown-Richtlinie

Diese Seite erklärt, wie dieser Dienst das Urheberrecht unter dem DMCA (Digital Millennium Copyright Act, dem US-amerikanischen Urheberrechtsgesetz fürs Internet) behandelt. Wenn Sie Rechteinhaber sind und Ihr Werk ohne Ihre Erlaubnis über dieses Tool verarbeitet wird, erfahren Sie hier, was eine Takedown-Meldung ist, was eine gültige Meldung enthalten muss und wohin Sie sie senden.

**Kernaussagen**

- Wir halten uns an den DMCA und reagieren auf gültige Takedown-Meldungen.
- Eine gültige Meldung braucht sechs bestimmte Elemente — unten als Checkliste.
- Meldungen gehen über die Kontaktseite der Website (Thema: Urheberrecht).
- Wenn ein Dokument versehentlich gesperrt wurde, kann die betroffene Partei eine Gegendarstellung einreichen.
- Diese Seite ist eine allgemeine Information, keine Rechtsberatung.

## Unser Engagement

Wir respektieren das geistige Eigentum von Autoren, Verlagen und Kreativen. Wenn wir eine gültige DMCA-Meldung erhalten, prüfen wir sie und handeln. Dieses Tool ist dafür da, dass Menschen persönliche Kopien von Dokumenten behalten können, zu deren Aufbewahrung sie berechtigt sind — nicht, um fremde urheberrechtlich geschützte Werke ohne Erlaubnis weiterzuverbreiten.

## Wie der Dienst Dateien Behandelt

Ein bisschen Kontext, was „Entfernung" hier bedeutet. Dieses Tool ist keine Dokumentenbibliothek — es hostet keine öffentliche Sammlung von Dateien und veröffentlicht niemandes Werk erneut. Wenn Sie einen Link einfügen, wird das Dokument auf dem Server verarbeitet, um Ihr PDF zu erzeugen; temporäre Arbeitsdateien werden danach automatisch gelöscht, und eine kurzzeitige Cache-Kopie kann behalten werden, damit wiederholte Anfragen schneller laden. Nichts wird veröffentlicht oder öffentlich geteilt.

Eine Takedown-Anfrage bedeutet hier also, das Dokument von der Verarbeitung auszuschließen — es kann dann nicht mehr über das Tool heruntergeladen werden. Das Original auf Scribd ist davon nicht betroffen; dafür ist Scribd selbst zuständig.

## Was eine DMCA-Meldung Ist

Eine DMCA-Takedown-Meldung ist eine formale Aufforderung eines Rechteinhabers (oder einer dazu bevollmächtigten Person) an einen Dienst, den Zugang zu Material zu stoppen, das seiner Ansicht nach sein Urheberrecht verletzt. Es ist ein Standardverfahren im ganzen Web — das gleiche Grundformat funktioniert für ein Hosting-Unternehmen genauso wie für ein Tool wie dieses.

Eine Meldung einzureichen ist keine Klage. Es ist eine Mitteilung: „Das ist mein Werk, es wird ohne meine Erlaubnis genutzt, bitte stoppen Sie das." Dienste, die den DMCA einhalten, nehmen gültige Meldungen ernst, weil das Gesetz die schützt, die mitmachen — und nicht die, die sie ignorieren.

## Eine Meldung Einreichen: Die Sechs Pflicht-Elemente

Damit eine Meldung gültig ist, braucht sie alle sechs folgenden Punkte. Nutzen Sie das als Checkliste vor dem Absenden:

1. **Identifizieren Sie das urheberrechtlich geschützte Werk.** Beschreiben Sie Ihr Werk — Titel, und einen Link zum Original, falls es online veröffentlicht ist.
2. **Identifizieren Sie das verletzende Material.** Die konkrete Scribd-URL, die über dieses Tool verarbeitet wird. Eine allgemeine Beschwerde ohne konkreten Link kann nicht bearbeitet werden.
3. **Ihre Kontaktinformationen.** Vollständiger Name, Organisation (falls vorhanden), Adresse, Telefonnummer und E-Mail — ein Kanal, über den wir Sie zu der Meldung erreichen können.
4. **Eine Gutgläubigkeitserklärung.** Eine Erklärung, dass Sie nach Treu und Glauben davon ausgehen, dass die Nutzung des Materials nicht vom Rechteinhaber, seinem Bevollmächtigten oder dem Gesetz autorisiert ist.
5. **Eine Richtigkeitsversicherung.** Eine Erklärung, unter Strafandrohung bei Meineid, dass die Angaben in Ihrer Meldung zutreffend sind und dass Sie befugt sind, im Namen des Rechteinhabers zu handeln.
6. **Ihre Unterschrift.** Physisch oder elektronisch — ein getippter vollständiger Name gilt als elektronische Unterschrift.

Fehlende Teile verzögern alles. Der häufigste Grund, warum eine Meldung nicht bearbeitet werden kann, ist Punkt 2: kein konkreter Link. Fügen Sie ihn bei.

## Wohin Sie Sie Senden

Nutzen Sie die Kontaktseite der Website und wählen Sie das Thema Urheberrecht, mit allen sechs Punkten von oben. Das ist der Kanal, der für solche Anfragen überwacht wird — an anderer Stelle riskieren Sie, dass sie ungelesen liegen bleibt.

## Was Nach dem Einreichen Passiert

Der Ablauf in einfachen Worten:

1. **Wir erhalten Ihre Meldung** über die Kontaktseite.
2. **Wir prüfen die Vollständigkeit** — alle sechs Elemente vorhanden, konkreter Link dabei.
3. **Wir handeln bei gültigen Meldungen** — das Dokument wird von der Verarbeitung ausgeschlossen und kann nicht mehr über das Tool heruntergeladen werden.
4. **Wir dokumentieren** die Meldung und die getroffene Maßnahme.

Wie schnell das geht, hängt von Volumen und Komplexität ab — eine feste gesetzliche Frist können wir hier nicht versprechen. Was wir sagen können: Vollständige Meldungen mit konkretem Link bewegen sich am schnellsten, weil nichts zurückgefragt werden muss.

## Gegendarstellungen

Manchmal sind Sperrungen Fehler — ein Dokument wird markiert, das es nicht sein sollte. Wenn Sie glauben, dass ein Dokument zu Unrecht ausgeschlossen wurde, können Sie eine Gegendarstellung mit folgenden Angaben einreichen:

- Ihre Kontaktdaten
- Identifizierung des gesperrten Materials (der konkrete Link)
- Eine Erklärung, dass Sie sich der Zuständigkeit der Gerichte Ihrer Region unterwerfen
- Ihre Unterschrift (physisch oder elektronisch)

Eine ehrliche Empfehlung: Holen Sie sich vor einer Gegendarstellung rechtlichen Rat. Die damit verbundenen Erklärungen haben echtes Gewicht, und ein Anwalt kann Ihnen in zehn Minuten sagen, ob Ihr Fall dafür infrage kommt.

## FAQ

**Was ist eine DMCA-Takedown-Meldung?**
Eine formale Aufforderung eines Rechteinhabers an einen Dienst, den Zugang zu Material zu stoppen, das seiner Ansicht nach sein Urheberrecht verletzt. Sie braucht die sechs bestimmten Elemente, um gültig zu sein — oben in der Checkliste.

**Wie melde ich mein urheberrechtlich geschütztes Werk hier?**
Senden Sie eine Meldung über die Kontaktseite der Website (Thema: Urheberrecht) mit allen sechs Pflicht-Elementen, einschließlich der konkreten Scribd-URL.

**Brauche ich einen Anwalt, um eine Meldung einzureichen?**
Nein — jeder Rechteinhaber oder sein Bevollmächtigter kann eine Meldung einreichen. Aber wenn Ihr Fall kompliziert ist, hilft rechtlicher Rat.

**Was, wenn ich eine Meldung eingereicht habe und nichts passiert?**
Prüfen Sie zuerst: Enthielt Ihre Meldung alle sechs Elemente, besonders den konkreten Link? Unvollständige Meldungen können nicht bearbeitet werden. War sie vollständig, fragen Sie über denselben Kontaktkanal nach.

**Kann ein gesperrtes Dokument wiederhergestellt werden?**
Ja, über das Gegendarstellungsverfahren oben — wenn die Sperrung ein Fehler war.

**Entfernt eine Takedown-Anfrage hier das Dokument von Scribd?**
Nein. Sie stoppt nur die Verarbeitung des Dokuments über dieses Tool. Das Original auf Scribd ist Sache von Scribd selbst.

## Fazit

Rechteinhaber haben einen klaren Weg: eine gültige Sechs-Elemente-Meldung über die Kontaktseite, und wir handeln. Nutzer haben eine klare Grenze: Dieses Tool ist für Dokumente, zu deren Aufbewahrung sie berechtigt sind. Die Fair-Use-Seite erklärt diese andere Seite der Grenze in einfacher Sprache.
